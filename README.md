# HR Analytics Dashboard

## 🎯 Objective

This project aims to assist organizations in improving employee performance and reducing attrition by creating an interactive HR Analytics dashboard using Power BI Desktop.

## 🛠 Tools Used

* **Power BI Desktop**: For data visualization and dashboard creation.
* **Power Query**: For data cleaning and transformation.
* **DAX**: For data analysis and creating calculated columns and measures.

## 🧹 Data Cleaning and Transformation with Power Query

1. **Connect to Employee Data**: Import employee data from Excel into Power BI.
2. **Data Transformation**:

   * Remove duplicates.
   * Rename columns for clarity.
   * Change data types as needed.
3. **Template Creation**: Create a template for one sheet in Power Query transformations and apply the same transformations to all sheets.
4. **Parameterization**: Create a parameter to select the desired data based on specific conditions.
5. **Function Creation**: Encapsulate all steps into a function to be reused for future sheets and data.
6. **Load Data**: Load and apply the cleaned data into Power BI.

## 📊 Data Analysis with DAX

* **Measure and Column Creation**: Use DAX functions such as COUNT and SUM to explore the cleaned data.
* **KPI Development**: Develop Key Performance Indicators (KPIs) to assess employee performance and retention.

## 📈 Power BI Dashboard Visualization

1. **Layout Design**: Design the dashboard layout for optimal user experience.
2. **Data Aggregation**: Create a measure table to aggregate and display data using DAX functions.
3. **Visualization Creation**:

   * Add a title: "HR Dashboard".
   * Add a Month column as a slicer.
   * Incorporate informative KPIs.
   * Add various charts: Bar chart, Pie chart, Column chart, Cards, Matrix chart, Donut chart, etc.

## ✅ Conclusion

* **Attrition Reduction**: Identified key factors contributing to employee attrition and implemented strategies to reduce it.
* **Hiring Process Improvement**: Enhanced the hiring process through data-driven insights.
* **Employee Experience Enhancement**: Improved employee experience by addressing identified issues.
* **Workforce Productivity**: Increased workforce productivity through targeted interventions.
* **Employee Trust**: Gained employee trust by demonstrating commitment to their well-being.
